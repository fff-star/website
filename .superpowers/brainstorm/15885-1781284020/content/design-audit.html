🔍 Current Design Audit — fff.sh

"Arctic Frost" theme — 12 issues found across the site

Critical Issues

❌ Homepage Blog List is Raw Text

No card styling on index.astro — just inline date + link. Completely unstyled compared to PostEntry cards.

❌ Notes Folder Page Shows No Notes

/notes/[folder].astro only renders index.md content — the actual notes in each folder are never listed!

❌ Heavy Inline Styles Everywhere

Header, index, notes pages, tags pages all use raw style="" attributes instead of CSS classes. Inconsistent and unmaintainable.

Visual Quality Issues

🟡 No .page-header h1 Style

Multiple pages use <header class="page-header"><h1> but there's no CSS rule for it. Only referenced in @media query.

🟡 Typography Hierarchy Gap

h1=38px but h2=24px — a 14px gap. Post titles are 42px but page titles have no consistent sizing.

🟡 Tags & Notes Pages are Bare Lists

/tags/, /tags/[tag]/, /notes/ — all just text links with no visual cards, no hierarchy, no design treatment.

🟡 Dark Mode Code Blocks Lack Contrast

Code block bg (#111827) vs entry bg (#151d2e) — nearly identical. Code blocks don't stand out in dark mode.

Polish & Detail Issues

🔵 Cold Palette Feels Clinical

"Arctic Frost" is all icy whites and slate blues. No warmth, no personality beyond the accent blue.

🔵 No Visual Flair

No gradients, no decorative elements, no texture. The section-divider gradient exists but may not be used anywhere.

🔵 Blog Archive Doesn't Use PostEntry

/blog/ uses raw archive styling instead of the PostEntry.astro card component. Inconsistent with note listings.

🔵 Atkinson Hyperlegible at 18px is Chunky

Body font is large for a reading site. The font prioritizes accessibility legibility over aesthetic refinement.

🔵 No Backlinks or Footer Nav on Note Pages

Note pages have Backlinks component imported but the TODO for prev/next nav is marked false. Missing navigation dead-ends.
