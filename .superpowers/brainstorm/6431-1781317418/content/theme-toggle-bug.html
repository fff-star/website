🔴 Critical Bug: Theme Toggle Icons Are Invisible

Astro’s CSS scoping silently breaks the [data-theme] selectors — the toggle button renders with no icon at all

What's Happening

The ThemeToggle component uses <style> (scoped by Astro) to show/hide sun/moon icons based on data-theme on <html>. But Astro prepends its scoping attribute to EVERY compound selector part:

ThemeToggle.astro — what the developer wrote
/* Intended CSS */
[data-theme='dark'] .sun { display: none !important; }
[data-theme='dark'] .moon { display: inline-flex !important; }
⬇
Compiled CSS output — what Astro actually produces
/* Astro scoped the data-theme selector — it can NEVER match */
[data-astro-cid-lfoluaxz][data-theme=dark] .sun[data-astro-cid-lfoluaxz] { ... }

Why it fails: data-theme is set on <html>, but the scoping attribute data-astro-cid-* is on the ThemeToggle button. No element has both attributes, so the selector matches nothing. Both icons stay display:none (their inline default).

The Fix

Change the <style> block in ThemeToggle.astro to <style is:global>, or move the data-theme rules to global.css. Since these rules target <html> state — inherently global — they must not be scoped.
