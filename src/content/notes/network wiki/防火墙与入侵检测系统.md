# 防火墙与入侵检测系统

> 参考：Kurose §8.9

**防火墙（Firewall）**和**入侵检测系统（Intrusion Detection System, IDS）**是组织网络**运行安全（Operational Security）**的两大支柱。防火墙控制进出网络的流量，IDS 检测网络中可疑的活动。

## 防火墙

防火墙是位于组织内部网络与公共因特网之间的硬件或软件，根据预定义的安全规则**决定转发还是丢弃**每个数据报。

### 三种类型

#### 1. 无状态分组过滤器（Stateless Packet Filter）

基于每个分组的首部字段独立做出决策（不跟踪连接状态）。典型过滤规则检查：

| 字段 | 示例用途 |
|------|---------|
| 源/目的 IP 地址 | 阻止来自黑名单 IP 的流量 |
| 协议类型（TCP/UDP/ICMP） | 允许 TCP 但阻止 ICMP |
| 源/目的端口号 | 允许 HTTP（端口 80）但阻止其他服务 |
| TCP 标志位（SYN/ACK/RST） | 阻止外部发起的 TCP 连接（SYN=1, ACK=0） |
| ICMP 类型 | 允许 `echo reply` 但阻止 `echo request` |

ACL（Access Control List）按序匹配规则——遇到第一个匹配规则即执行对应操作。通常最后一条默认规则为"拒绝所有"。

**局限性**：无法检测应用层攻击（如恶意 HTTP 请求），无法感知连接状态。

#### 2. 有状态分组过滤器（Stateful Packet Filter）

维护每个 TCP 连接的**状态表**，记录已建立的连接（包括源/目的 IP、端口和当前状态）：

- 允许内部主机发起到外部的 TCP 连接（跟踪三次握手 → 已建立状态）
- 自动允许属于已建立连接的**返回流量**
- 阻止伪装成"已建立连接"的外部攻击流量

有状态过滤器比无状态过滤更精确，因为决策基于连接上下文而非仅单个分组。

#### 3. 应用网关（Application Gateway）

**应用网关**（也称**应用级网关**或**代理防火墙**）在应用层运行，理解特定应用协议（HTTP、FTP、SMTP、DNS）。

工作方式：
1. 外部客户端与防火墙建立 TCP 连接（防火墙作为"代理"）
2. 防火墙检查应用层数据（如 HTTP 请求的 URL、方法，SMTP 的邮件头）
3. 如果应用数据符合策略，防火墙与真实的内部服务器建立第二条 TCP 连接，中继数据

**优点**：可以进行深度内容检查，如过滤含有恶意 URL 的 HTTP 请求、阻止含有可执行附件的 SMTP 邮件。

**缺点**：每种应用需要单独的代理程序，计算开销大（两条连接 + 应用层解析），可能需要修改客户端配置。

### 三种类型的层次对比

| | 无状态过滤器 | 有状态过滤器 | 应用网关 |
|---|---|---|---|
| **工作层级** | 网络层/运输层 | 运输层 | 应用层 |
| **状态跟踪** | 无 | 按连接跟踪 | 理解应用语义 |
| **检查深度** | 仅首部字段 | 首部 + 连接状态 | 应用层内容 |
| **性能开销** | 低 | 中 | 高 |
| **防御能力** | 基本 | 较好 | 强（深度检查） |

实际部署常组合使用——例如在边界路由器上配置无状态过滤，在内部网络入口部署有状态过滤器和应用网关。

## 入侵检测系统（IDS）

防火墙基于规则**阻止**已知恶意流量，但无法检测隐藏在合法流量中的攻击。IDS 通过**深度分组检查（Deep Packet Inspection）**检测可疑活动。

### IDS vs IPS

- **IDS（Intrusion Detection System）**：检测并**报警**，不主动阻止流量。管理员收到告警后手动响应
- **IPS（Intrusion Prevention System）**：检测并**主动阻断**恶意流量，可实时丢弃攻击分组

### 检测方法

| 方法 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| **基于签名（Signature-based）** | 维护已知攻击的特征库，匹配网络流量 | 误报率低，已知攻击准确检测 | 无法检测新型（零日）攻击 |
| **基于异常（Anomaly-based）** | 建立正常流量基线，标记偏离基线的活动 | 可检测新型攻击 | 误报率高，基线难以准确定义 |

### 部署位置

- **网络 IDS（NIDS）**：在网络入口/关键节点部署，监控流经的所有流量
- **主机 IDS（HIDS）**：在关键服务器/主机上运行，监控系统调用、文件完整性和日志

### 典型 IDS 系统

- **Snort**：著名的开源 NIDS，使用基于签名的规则语言（Snort rules）
- **Bro/Zeek**：开源网络安全监控框架，偏重行为分析和协议解析

## 纵深防御（Defense in Depth）

防火墙和 IDS/IPS 是组织网络安全的最后一道防线（运行安全），应配合其他层次的安全机制形成**纵深防御**：

| 层次 | 安全机制 |
|------|---------|
| 应用层 | PGP、DNSSEC |
| 运输层 | TLS |
| 网络层 | IPsec |
| 链路层 | WPA2 / 802.11i |
| 运行安全 | 防火墙、IDS/IPS |
