# 无线与移动性对 TCP 的影响

> 参考：Kurose §7.6

TCP 是为有线网络设计的——其核心前提假设是：**丢包 = 网络拥塞**。但无线链路的误码率远高于有线链路，丢包可能因噪声、干扰或衰落导致，与拥塞完全无关。当 TCP 错误地将无线丢包解释为拥塞信号并减速时，无线链路上的 TCP 吞吐量可能大幅下降。

## 无线链路上的 TCP 问题

### 三个根本原因

1. **无线误码丢包**：无线链路的 BER 远高于有线（$10^{-6}$ 到 $10^{-4}$，甚至更高）。即使网络毫无拥塞，纯粹出于无线信道的损坏，TCP 报文段也经常丢失。TCP 发送方不分青红皂白地将所有丢包视为拥塞——超时后将 cwnd 减为 1 MSS，丢包率高的无线链路导致 TCP 频繁地从慢启动重新开始

2. **端点移动**：当移动节点在两个网络之间切换时（如 WiFi AP 之间或蜂窝基站之间），切换过程可能导致短暂的数据流中断（分组丢弃、重新排序、延迟变化）。TCP 将这种暂时中断也解释为严重拥塞

3. **带宽波动**：无线链路的可用带宽随时间大幅变化（信号波动、小区负载变化）。TCP 难以在剧烈变化的容量上准确估计可用的发送速率

### 一个具体场景

假设发送方通过有线网络到 AP，AP 到无线接收方是一段有 1% 丢包率的无线链路。使用前面 TCP 吞吐量公式：

$$\text{吞吐量} \approx \frac{1.22 \times \text{MSS}}{\text{RTT} \times \sqrt{p}}$$

有线链路的丢包率 $p_{\text{wired}} \approx 10^{-6}$ 几乎不影响吞吐量。无线链路的 $p_{\text{wireless}} = 0.01$ 意味着每 100 个报文段之中就有一个丢失——TCP 将频繁减速，实际吞吐量可能仅为理论带宽的很小一部分。

## 改善无线 TCP 性能的方法

### 链路层重传（Link-Layer Retransmission）

在最接近无线链路的位置处理无线丢包——让无线链路协议（如 802.11）在链路层重传丢失的帧。链路层 ACK + 重传机制在微秒至毫秒时间尺度上将丢包恢复，从而向 TCP 隐藏了大部分无线误码丢包。

**局限**：在 TCP 的 RTT 很大时，链路层重传可能与 TCP 的重传定时器交互（TCP 超时后也启动重传），导致不必要的重复重传。某些情况下（如链路中断数秒、跨基站切换），链路层重传也无法完全掩盖。

### 分离连接（Split Connection）

将 TCP 连接在 AP 处分为两段——有线段（发送方 ↔ AP）和无线段（AP ↔ 接收方）。有线段继续使用标准 TCP。无线段可以使用针对无线优化的传输协议（如更小的 RTO、更高的重传激进程度或甚至 UDP 承载）。

**缺点**：打破了 TCP 的端到端语义。ACK 从 AP 返回到发送方，意味着实际数据可能尚未到达最终接收方。更关键的是，AP 处是单点故障——如果 AP 在收到数据后崩溃，已向发送方确认的数据将从系统中完全丢失。

### 本地重传（Local Retransmission）

让 AP 监控无线链路的数据传输。当 AP 检测到无线侧的丢包时，它从自身的缓存中重传（不等发送方 TCP 定时器超时）。这比等待端到端重传快得多，特别是对于 RTT 较长的连接。

### 显式无线丢包通知

修改 TCP 的端到端语义：让接收方有能力区分丢包的**原因**。例如，允许 TCP 接收方通过显式标记告知发送方"这个丢包是无线链路上的误码导致的，不是拥塞"。发送方在收到这样的通知后可以只重传丢失的数据（而不减窗）。

然而，如何可靠地让接收方确定丢包的原因（无线误码 vs 拥塞）在端到端基础上仍然是一个开放的研究问题。

## TCP 在移动切换中的表现

当移动节点在 WiFi AP 或蜂窝基站之间切换时，数据路径发生变化。不仅可能出现短暂丢包，**RTT 也可能突变**——当新路径的距离和容量不同时，TCP 的动态 RTT 估计（EstimatedRTT 和 DevRTT）需要时间收敛。在收敛过程中，定时器可能设置得过短（导致不必要的超时）或过长（降低吞吐量）。

这也是 [[QUIC]] 协议（HTTP/3）相比 TCP 的一个重要优势——QUIC 使用连接 ID 而非 IP/端口四元组标识连接，网络切换时不中断，无需重建 TCP 连接或重新执行慢启动。

## 总结

无线网络和移动性从根本上挑战了 TCP 的设计假设。虽然链路层重传在实践中有效减轻了大部分无线丢包问题，但彻底的解决方案（如 QUIC）需要重新审视运输层本身的设计原则——这正是 HTTP/3 选择 QUIC 而非 TCP 的深层原因之一。
