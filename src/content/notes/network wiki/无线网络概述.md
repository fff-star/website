# 无线网络概述

> 参考：Kurose §7.1

无线网络是当今最令人兴奋的网络技术领域之一。从 Wi-Fi 热点到 4G/5G 蜂窝数据，无线链路将数十亿设备连接到因特网。本章关注**无线网络和移动网络**——两者通常紧密相关，但在概念上是独立的：**无线**指的是物理链路的传输技术，**移动**指的是用户在改变网络连接点时维持通信的能力。

## 无线网络的组成元素

无线网络的拓扑由以下基本元素构成：

**无线主机（Wireless Host）**：运行应用程序的端系统设备——笔记本电脑、智能手机、平板电脑、IoT 设备等。无线主机本身可能具备移动性（可携带、可移动），也可能不具备（如固定位置的无线传感器）。

**无线链路（Wireless Link）**：主机通过无线通信链路连接到网络。无线链路使用电磁波在空气中传播（射频、微波、红外线等），与有线链路（铜线、光纤）在传输特性、误码率、传播方式上有根本差异。

**基站（Base Station, BS）**：在**基础设施模式**中，基站是无线网络的核心节点，负责协调与之关联的无线主机的通信。基站通过有线网络连接到更大的网络基础设施（如因特网）。基站的名称随无线网络技术而异：

| 无线网络技术 | 基站的名称 |
|------------|----------|
| Wi-Fi（802.11）| **接入点（Access Point, AP）** |
| 4G/5G 蜂窝网络 | **基站（Base Station, eNodeB/gNB）** |
| 蓝牙 | 主设备（Master） |

基站通过有线的以太网链路（或专用的光纤回传）连接到路由器和因特网，将无线网络与有线网络桥接在一起。

**网络基础设施（Network Infrastructure）**：基站所连接的有线网络（如企业以太网、ISP 网络、因特网骨干），为无线主机提供访问更广泛网络资源的能力。

## 基础设施模式与自组织模式

无线网络根据是否存在基站分为两种模式：

### 基础设施模式（Infrastructure Mode）

无线主机与基站相关联，由基站协调通信。主机的所有通信（包括向同一网络中其他无线主机的数据传输）都通过基站中转：

> 主机 A → AP → 有线网络 → AP → 主机 B

基础设施模式下，基站作为**中继和协调点**。Wi-Fi 热点和蜂窝网络都属于基础设施模式无线网络。

### 自组织模式（Ad Hoc Mode）

无线主机**不通过基站**直接相互通信。主机彼此发现、自我组织成一个临时网络（ad hoc network），每个节点可以充当中继——由节点 A 发出的帧可能经由节点 C 中继再到达节点 B。自组织网络**没有集中式控制器**，所有路由、接入和命名协议是分布式的。

自组织网络的实例包括：临时会议中笔记本电脑之间直接建立的 Wi-Fi 网络、灾害救援场景中无需基站的通信网络、军事战场网络以及车辆自组织网络（VANET）。

## 单跳与多跳无线网络

跨越基础设施/自组织的分类，还可以根据**跳数**进一步分类：

| | 单跳（Single-Hop） | 多跳（Multi-Hop） |
|---|---|---|
| **基础设施模式** | 主机 ↔ AP（典型 Wi-Fi 使用方式） | 无线 mesh 网络（主机通过其他主机中继到达 AP） |
| **自组织模式** | 蓝牙设备直接配对 | 移动自组织网络（MANET）、VANET、无线传感器网络 |

最典型的日常 Wi-Fi 使用是**单跳基础设施模式**，而无线 mesh 网络（如家用 mesh Wi-Fi 系统、社区无线网络）属于多跳基础设施模式。

## 无线网络的分类全景

因特网工程任务组（IETF）和学术界通常按**跳数**和**覆盖范围**分类无线网络：

| 分类 | 覆盖范围 | 典型技术 |
|------|---------|---------|
| **无线个域网（WPAN）** | 几米 | 蓝牙、ZigBee |
| **无线局域网（WLAN）** | 几十米 | Wi-Fi（802.11） |
| **无线城域网（WMAN）** | 几公里 | WiMAX（802.16） |
| **无线广域网（WWAN）** | 数十公里 | 4G/5G 蜂窝网络 |

这些分类之间并非严格隔离——现代无线通信技术（如 5G）正模糊这些边界，支持从窄带到超宽带的灵活覆盖范围。
