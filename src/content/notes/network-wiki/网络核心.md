# 网络核心

> 参考：Kurose §1.3

网络核心（network core）是由分组交换机和通信链路构成的网状结构，将因特网边缘的端系统互相连接起来。打个比喻：如果说网络边缘的端系统是建筑物，那么网络核心就是连接这些建筑物的高速公路、道路和路口网络。

## 核心功能

网络核心的基本任务是**将数据从源端系统传输到目的端系统**。这一任务通过两种基本方式实现：

- **分组交换（packet switching）**：数据被分割为分组（packet），每个分组独立地在网络中逐跳转发。因特网采用这种方式。
- **电路交换（circuit switching）**：通信前在源和目的地之间建立一条专用的端到端电路（连接），通信期间独占该电路的资源。传统电话网络采用这种方式。

## 分组交换 vs 电路交换 概览

| | 分组交换 | 电路交换 |
|---|---------|---------|
| 资源分配方式 | 按需使用，不预留 | 预先分配，独占资源 |
| 拥塞可能性 | 存在排队和丢包 | 无拥塞（资源专属） |
| 资源利用率 | 高（统计复用） | 低（空闲时资源闲置） |
| 适用场景 | 突发性数据（因特网流量） | 恒定速率流（如传统电话） |
| 计费模式 | 按数据量 | 按时长/距离 |

## 网络的网络

单个网络无法覆盖全球。因特网实际上是由成千上万个 ISP 网络互相连接形成的**网络之网络（network of networks）**。这些 ISP 网络形成了多层层次结构，其中高层 ISP（Tier-1 ISP）位于顶层，区域 ISP 位于中间，接入 ISP 位于底层。ISP 之间通过存在点（PoP）、多宿（multi-homing）、对等（peering）和因特网交换点（IXP）实现互联。近年来，大型内容提供商（如 Google）也建立了自己的专用网络，直接与低层 ISP 对等。
