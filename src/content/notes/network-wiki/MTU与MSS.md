# MTU 与 MSS

> 参考：Kurose §3.5.1, §4.3.2

**MTU（最大传输单元）**和 **MSS（最大报文段大小）**是网络层和运输层中的两个关键长度限制。理解它们之间的区别和关系，以及它们对上层协议的影响，是理解因特网设计中层次协作的重要一环。

## MTU（最大传输单元）

**最大传输单元（Maximum Transmission Unit, MTU）**是链路层帧能承载的最大有效载荷（不包括链路层首部）。每种链路层协议有各自的 MTU。

| 链路层协议 | MTU |
|-----------|-----|
| 以太网（Ethernet）| 1,500 字节 |
| 802.11 Wi-Fi | 2,304 字节 |
| PPPoE | 1,492 字节 |
| FDDI | 4,352 字节 |
| 令牌环（Token Ring）| 4,464 字节 |
| 广域网链路 | 常见 576 字节 |

MTU 约束意味着：网络层 IP 数据报必须 ≤ 出链路的 MTU。若数据报大于 MTU，路由器需执行 **IP 分片**（[[IP分片]]）或将数据报丢弃（IPv6）。

## MSS（最大报文段大小）

**最大报文段大小（Maximum Segment Size, MSS）**是 TCP 报文段中**应用层数据（有效载荷）的最大大小**，不包括 TCP 首部和 IP 首部。MSS 的设置目的是避免 IP 分片——让 TCP 报文段恰好适合链路层的 MTU。

$$\text{MSS} = \text{MTU} - \text{IP 首部} - \text{TCP 首部}$$

典型值：
- 以太网 MTU = 1,500，IP 首部 = 20，TCP 首部 = 20
- **MSS = 1,500 − 20 − 20 = 1,460 字节**

对于 IPv6（固定 40 字节基本首部），以太网上的 MSS = 1,500 − 40 − 20 = **1,440 字节**。

## MTU 与 MSS 的层次关系

```
┌──────────────────────────┐
│      应用层数据            │
├──────────────────────────┤ ← TCP 报文段
│      TCP 首部 (20B)       │
├──────────────────────────┤ ← IP 数据报
│      IP 首部 (20B)        │     │
├──────────────────────────┤ ← 链路层帧  │ MTU
│   链路层首部 + CRC         │     │      │
└──────────────────────────┘
         ↑──── MTU ────↑
         ↑────── MSS ──────↑
```

MSS 始终比 MTU 小，差异为 IP 和 TCP 的首部开销。TCP 的 MSS 排除了自己的首部和 IP 首部——这确保了最终的 IP 数据报不会超过 MTU。

## MSS 的协商

TCP 连接建立时，双方通过三次握手中的 **MSS 选项（TCP Options 字段）**通告自己的 MSS。双方取较小值作为实际使用的 MSS。这使得不同 MTU 的链路之间可以正常工作。

## 路径 MTU 发现（Path MTU Discovery）

发送方往往不知道路径上所有链路的 MTU。**路径 MTU 发现**是一种端到端技术：

1. 发送方使用出接口的 MTU 作为初始值
2. 在 IP 数据报首部中设置 **DF（Don't Fragment）**位 = 1
3. 若路径上某路由器因 MTU 过小而无法转发，则**丢弃数据报**并向发送方发送 ICMP "Fragmentation Needed" 消息，包含该链路的 MTU
4. 发送方降低 MSS 并重传
5. 重复直到数据报成功到达目的地，此时得到路径上的最小 MTU = **路径 MTU（Path MTU）**

路径 MTU 发现避免了中间路由器的分片开销（IPv6 强制要求此机制，因为中间路由器不再分片）。

## 为什么需要 MSS？

如果没有 MSS，发送方可能发送一个 64 KB 的 TCP 报文段。TCP 将它交给 IP 封装为 64 KB 数据报，再交给链路层时必然分片——64 KB / 1,500 B ≈ 44 个分片。丢失其中一个分片意味着整个数据报作废、所有分片重传。MSS 的存在使 TCP 报文段从源头就不超过 MTU，避免了分片带来的效率损失。

这就是为什么 **MSS 是 TCP 流的最优粒度**——在避免 IP 分片的前提下最大化每报文段的吞吐量。
